# Naveen.R Portfolio

Open `index.html` in any browser. It is one self-contained file (HTML, CSS and JavaScript, with images embedded), so it also works on any static host such as GitHub Pages, Netlify or Vercel.

`assets/` holds the original project and certificate images for your own use or re-editing.

## Things to set (script near the bottom of index.html)
- `RESUME_URL` : link to your resume PDF, so the Download Resume button works.
- `FORM_ENDPOINT` : a form service URL (for example Formspree). Without it the form opens your email app.
- `BIRD_CFG` (optional): add `window.BIRD_CFG={count:1200,radius:150,strength:1500}` before the bird script to tune the flock.
